# 🔹 2469. Convert the Temperature

## 🧠 Problem Statement
You are given a non-negative floating point number `celsius`, representing the temperature in Celsius.

Convert the temperature into:
- Kelvin
- Fahrenheit

Return the answer as an array:

```cpp
[kelvin, fahrenheit]
```

## 📌 Examples

```
Input:  celsius = 36.50
Output: [309.65000,97.70000]

Explanation:
Kelvin     = 36.50 + 273.15 = 309.65
Fahrenheit = 36.50 × 1.80 + 32.00 = 97.70
```

```
Input:  celsius = 122.11
Output: [395.26000,251.79800]
```

---

## 💡 Approach
- Calculate Kelvin using:
  - `celsius + 273.15`
- Calculate Fahrenheit using:
  - `celsius * 1.80 + 32.00`
- Store both values in a vector
- Return the vector

---

## ⚡ C++ Solution 

```cpp
class Solution {
public:
    vector<double> convertTemperature(double celsius) {

        vector<double> ans;

        double kelvin = celsius + 273.15;

        double fahrenheit = celsius * 1.80 + 32.00;

        ans.push_back(kelvin);

        ans.push_back(fahrenheit);

        return ans;
    }
};
```
