# 🔹 507. Perfect Number

## 🧠 Problem Statement
A perfect number is a positive integer that is equal to the sum of its positive divisors, excluding the number itself.

A divisor of an integer `x` is a number that divides `x` evenly.

Return `true` if the given number is a perfect number, otherwise return `false`.

---

## 📌 Examples

```
Input:  num = 28
Output: true

Explanation:
Divisors of 28:
1, 2, 4, 7, 14

Sum = 1 + 2 + 4 + 7 + 14 = 28

So, 28 is a perfect number.
```

```
Input:  num = 7
Output: false
```

---

## 💡 Approach
- Initialize `sum = 0`
- Traverse from `1` to `num - 1`
- Check if the current number divides `num`
- If yes, add it to `sum`
- Finally compare:
  - If `sum == num` → perfect number
  - Otherwise → not a perfect number

---

## ⚡ C++ Solution 

```cpp
class Solution {
public:
    bool checkPerfectNumber(int num) {

        int sum = 0;

        for(int i = 1; i < num; i++){

            if(num % i == 0){
                sum += i;
            }
        }

        return sum == num;
    }
};
```

---

## 🧪 Dry Run

```cpp
num = 6

Divisors of 6:
1, 2, 3

Sum:
1 + 2 + 3 = 6

Since sum == num,
6 is a perfect number.
```
