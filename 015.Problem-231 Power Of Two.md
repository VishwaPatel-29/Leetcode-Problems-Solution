# 🔹 231. Power of Two

## 🧠 Problem Statement
Given an integer `n`, return `true` if it is a power of two. Otherwise, return `false`.

## 📌 Examples

```
Input:  n = 1
Output: true

Explanation:
2⁰ = 1
```

```
Input:  n = 16
Output: true

Explanation:
2⁴ = 16
```

```
Input:  n = 3
Output: false
```

---

## 💡 Approach
- If `n <= 0`, return `false`
- Continuously divide the number by `2`
- If at any step the number is not divisible by `2`, return `false`
- If we successfully reach `1`, then the number is a power of two

---

## ⚡ C++ Solution 

```cpp
class Solution {
public:
    bool isPowerOfTwo(int n) {

        if(n <= 0){
            return false;
        }

        while(n > 1){

            if(n % 2 != 0){
                return false;
            }

            n = n / 2;
        }

        return true;
    }
};
```
