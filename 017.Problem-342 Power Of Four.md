# 🔹 342. Power of Four

## 🧠 Problem Statement
Given an integer `n`, return `true` if it is a power of four. Otherwise, return `false`.

## 💡 Approach
- If `n <= 0`, return `false`
- Continuously divide the number by `4`
- If at any step the number is not divisible by `4`, return `false`
- If we successfully reach `1`, then the number is a power of four

---

## ⚡ C++ Solution 

```cpp
class Solution {
public:
    bool isPowerOfFour(int n) {

        if(n <= 0){
            return false;
        }

        while(n > 1){

            if(n % 4 != 0){
                return false;
            }

            n = n / 4;
        }

        return true;
    }
};
```
