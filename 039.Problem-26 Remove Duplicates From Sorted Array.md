# 🔹 26. Remove Duplicates from Sorted Array

## 🧠 Problem Statement
Given an integer array `nums` sorted in non-decreasing order, remove duplicates in-place such that each unique element appears only once.

The relative order of elements should remain the same.

Return the number of unique elements `k`.

The first `k` elements of `nums` should contain the unique elements.

---

## 📌 Examples

```cpp
Input: nums = [1,1,2]

Output: 2, nums = [1,2,_]
```

### Explanation

```cpp
Unique elements are:
[1,2]

So, k = 2
```

---

```cpp
Input: nums = [0,0,1,1,1,2,2,3,3,4]

Output: 5, nums = [0,1,2,3,4,_,_,_,_,_]
```

### Explanation

```cpp
Unique elements are:
[0,1,2,3,4]

So, k = 5
```

---

## 💡 Approach
- Use a pointer `k` to store the position of the next unique element.
- Start traversing from index `1`
- Compare current element with previous element:
  - If different:
    - Store current element at index `k`
    - Increment `k`
- Return `k` at the end

---

## ⚡ C++ Solution

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {

        int k = 1;

        for(int i = 1; i < nums.size(); i++){

            if(nums[i] != nums[i - 1]){

                nums[k] = nums[i];

                k++;
            }
        }

        return k;
    }
};
```


```cpp
nums[k] = nums[4]

```

```cpp
[1,2,3,2,3]

k = 3
```
