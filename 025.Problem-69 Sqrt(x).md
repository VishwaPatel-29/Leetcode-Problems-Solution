# 🔹 69. Sqrt(x)

## 🧠 Problem Statement
Given a non-negative integer `x`, return the square root of `x` rounded down to the nearest integer.

The returned integer should also be non-negative.

You must not use any built-in exponent function or operator.

```cpp
Do not use:
pow(x, 0.5)
x ** 0.5
```

---

## 📌 Examples

```cpp
Input: x = 4
Output: 2

Explanation:
The square root of 4 is 2.
So, we return 2.
```

```cpp
Input: x = 8
Output: 2

Explanation:
The square root of 8 is 2.82842...

After rounding down,
the answer becomes 2.
```

---

## 💡 Approach
- Start a loop from `1`
- Check:
  - `i * i <= x`
- If true:
  - store `i` in `ans`
- Continue until the square becomes greater than `x`
- Return the last valid value of `i`

---

## ⚡ C++ Solution

```cpp
class Solution {
public:
    int mySqrt(int x) {

        int ans = 0;

        for(long long i = 1; i * i <= x; i++){

            ans = i;
        }

        return ans;
    }
};
```

---

## 🧪 Dry Run

### Example

```cpp
x = 10
```

### Iteration 1

```cpp
1 * 1 = 1

1 <= 10 → true

ans = 1
```

### Iteration 2

```cpp
2 * 2 = 4

4 <= 10 → true

ans = 2
```

### Iteration 3

```cpp
3 * 3 = 9

9 <= 10 → true

ans = 3
```

### Iteration 4

```cpp
4 * 4 = 16

16 <= 10 → false
```

Loop stops here.

### Final Answer

```cpp
ans = 3
```

Because:

```cpp
√10 = 3.162...
```

Rounded down becomes:

```cpp
3
```

## 🚀 Notes
- Time Complexity: `O(√x)`
- Space Complexity: `O(1)`
