# 🔹 1913. Maximum Product Difference Between Two Pairs

## 🧠 Problem Statement
The product difference between two pairs `(a, b)` and `(c, d)` is:

:contentReference[oaicite:0]{index=0}

Given an integer array `nums`, return the maximum product difference possible.

---

## 📌 Examples

```
Input:  nums = [5,6,2,7,4]
Output: 34

Explanation:

Largest pair:
6 × 7 = 42

Smallest pair:
2 × 4 = 8

Product Difference:
42 - 8 = 34
```

```
Input:  nums = [4,2,5,9,7,4,8]
Output: 64
```

---

## 💡 Approach
- Sort the array
- Find:
  - product of the two largest numbers
  - product of the two smallest numbers
- Return their difference

---

## ⚡ C++ Solution 

```cpp
class Solution {
public:
    int maxProductDifference(vector<int>& nums) {

        sort(nums.begin(), nums.end());

        int maxProduct =
            nums[nums.size() - 1] * nums[nums.size() - 2];

        int minProduct =
            nums[0] * nums[1];

        return maxProduct - minProduct;
    }
};
```

## 🧪 Dry Run

```cpp
nums = [4,2,5,9,7,1]

```

## 🚀 Notes
- Time Complexity: O(n log n)

- Space Complexity: O(1)
