# 🔹 263. Ugly Number

## 🧠 Problem Statement
An ugly number is a positive integer whose prime factors only include:

```cpp
2, 3, and 5
```

Given an integer `n`, return `true` if `n` is an ugly number, otherwise return `false`.

---

## 📌 Examples

```cpp
Input: n = 6
Output: true

Explanation:
6 = 2 × 3

Prime factors are only 2 and 3.
So, 6 is an ugly number.
```

```cpp
Input: n = 1
Output: true

Explanation:
1 has no prime factors.
So, it is considered an ugly number.
```

```cpp
Input: n = 14
Output: false

Explanation:
14 = 2 × 7

It contains prime factor 7.
So, 14 is not an ugly number.
```

---

## 💡 Approach
- If `n <= 0`, return `false`
- Keep dividing the number by:
  - `2`
  - `3`
  - `5`
- Remove all factors of `2`, `3`, and `5`
- At the end:
  - If `n == 1` → it is an ugly number
  - Otherwise → it is not an ugly number

---

## ⚡ C++ Solution

```cpp
class Solution {
public:
    bool isUgly(int n) {

        if(n <= 0){
            return false;
        }

        while(n % 2 == 0){
            n = n / 2;
        }

        while(n % 3 == 0){
            n = n / 3;
        }

        while(n % 5 == 0){
            n = n / 5;
        }

        return n == 1;
    }
};
```


```cpp

```

### Divide by 5

```cpp
5 / 5 = 1
```

### Final Check

```cpp
n == 1

Answer = true
```

---

### Example 2

```cpp
n = 14
```

### Divide by 2

```cpp
14 / 2 = 7
```

### Try dividing by 3

```cpp
7 % 3 != 0
```

### Try dividing by 5

```cpp
7 % 5 != 0
```

### Final Check

```cpp
n = 7

Answer = false
```

Because `7` is a prime factor other than `2`, `3`, and `5`.
