# 🔹 3668. Restore Finishing Order

## 🧠 Problem Statement
You are given an integer array `order` of length `n` and an integer array `friends`.

- `order` contains every integer from `1` to `n` exactly once, representing the IDs of the participants in their finishing order.
- `friends` contains the IDs of your friends. Each ID in `friends` is guaranteed to appear in the `order` array.

Return an array containing your friends' IDs in their finishing order.

---

## 📌 Examples

### Example 1

```text
Input:  order = [3,1,2,5,4], friends = [1,3,4]
Output: [3,1,4]
```

**Explanation:**

The finishing order is:

```text
[3, 1, 2, 5, 4]
```

Therefore, the finishing order of your friends is:

```text
[3, 1, 4]
```

### Example 2

```text
Input:  order = [1,4,5,3,2], friends = [2,5]
Output: [5,2]
```

**Explanation:**

The finishing order is:

```text
[1, 4, 5, 3, 2]
```

Therefore, the finishing order of your friends is:

```text
[5, 2]
```

---

## 💡 Approach

- Traverse the `order` array from left to right.
- For each participant ID in `order`, check whether it exists in the `friends` array.
- If it is a friend, add it to the answer array.
- Since `order` already represents the finishing order, the collected IDs will automatically be in the correct order.

---

## ⚡ C++ Solution

```cpp
class Solution {
public:
    vector<int> recoverOrder(vector<int>& order, vector<int>& friends) {

        vector<int> ans;

        for(int i = 0; i < order.size(); i++) {
            for(int j = 0; j < friends.size(); j++) {

                if(order[i] == friends[j]) {
                    ans.push_back(order[i]);
                }
            }
        }

        return ans;
    }
};
```

---

## 🧪 Dry Run

```cpp
order = [3,1,2,5,4]
friends = [1,3,4]
```

```text
i = 0 → order[0] = 3 → found in friends
ans = [3]

i = 1 → order[1] = 1 → found in friends
ans = [3,1]

i = 2 → order[2] = 2 → not found
ans = [3,1]

i = 3 → order[3] = 5 → not found
ans = [3,1]

i = 4 → order[4] = 4 → found in friends
ans = [3,1,4]
```

### Final Output

```text
[3,1,4]
```

---

## 🚀 Notes

- **Time Complexity:** `O(n × m)`
  - `n` = size of `order`
  - `m` = size of `friends`
- **Space Complexity:** `O(k)`
  - `k` = size of the answer array
