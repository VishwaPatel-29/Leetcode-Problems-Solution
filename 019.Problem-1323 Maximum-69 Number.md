# 🔹 1323. Maximum 69 Number

## 🧠 Problem Statement
You are given a positive integer `num` consisting only of digits `6` and `9`.

Return the maximum number you can get by changing at most one digit:
- `6` becomes `9`
- `9` becomes `6`

---

## 📌 Examples

```
Input:  num = 9669
Output: 9969

Explanation:
Changing the second digit from 6 to 9 gives 9969,
which is the maximum possible number.
```

```
Input:  num = 9996
Output: 9999
```

```
Input:  num = 9999
Output: 9999

Explanation:
No change is needed.
```

---

## 💡 Approach
- Convert the number into a string
- Traverse the string from left to right
- Find the first occurrence of `'6'`
- Change it to `'9'`
- Break the loop because changing the leftmost `6` gives the maximum number
- Convert the string back to integer

---

## ⚡ C++ Solution 

```cpp
class Solution {
public:
    int maximum69Number (int num) {

        string s = to_string(num);

        for(int i = 0; i < s.length(); i++){

            if(s[i] == '6'){
                s[i] = '9';
                break;
            }
        }

        return stoi(s);
    }
};
```
