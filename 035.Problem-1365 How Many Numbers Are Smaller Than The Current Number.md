# 🔹 1365. How Many Numbers Are Smaller Than the Current Number

## 🧠 Problem Statement
Given an array `nums`, for each `nums[i]`, find how many numbers in the array are smaller than it.

For every index `i`, count the number of indices `j` such that:

```cpp
j != i
and
nums[j] < nums[i]
```

Return the answer in an array.

---

## 📌 Examples

```cpp
Input: nums = [8,1,2,2,3]

Output: [4,0,1,1,3]
```

### Explanation

```cpp
For nums[0] = 8
Smaller numbers are: 1,2,2,3
Count = 4

For nums[1] = 1
No smaller number exists
Count = 0

For nums[2] = 2
Smaller number is: 1
Count = 1

For nums[3] = 2
Smaller number is: 1
Count = 1

For nums[4] = 3
Smaller numbers are: 1,2,2
Count = 3
```

---

```cpp
Input: nums = [6,5,4,8]

Output: [2,1,0,3]
```

---

```cpp
Input: nums = [7,7,7,7]

Output: [0,0,0,0]
```

---

## 💡 Approach
- Create an empty answer array `ans`
- Traverse every element using loop `i`
- For each element:
  - Initialize `count = 0`
  - Compare it with every other element using loop `j`
  - If `nums[j] < nums[i]`
    - Increase `count`
- Push `count` into `ans`
- Return the answer array

---

## ⚡ C++ Solution

```cpp
class Solution {
public:
    vector<int> smallerNumbersThanCurrent(vector<int>& nums) {

        vector<int> ans;

        for(int i = 0; i < nums.size(); i++){

            int count = 0;

            for(int j = 0; j < nums.size(); j++){

                if(nums[j] < nums[i]){

                    count++;
                }
            }

            ans.push_back(count);
        }

        return ans;
    }
};
```
