# 🔹 1672. Richest Customer Wealth

## 🧠 Problem Statement
You are given a 2D array `accounts` where:

```cpp
accounts[i][j]
```

represents the amount of money the `iᵗʰ` customer has in the `jᵗʰ` bank.

Return the wealth of the richest customer.

A customer's wealth is the sum of all money in their bank accounts.

---

## 📌 Examples

```
Input:  accounts = [[1,2,3],[3,2,1]]
Output: 6

Explanation:
1st customer:
1 + 2 + 3 = 6

2nd customer:
3 + 2 + 1 = 6

Maximum wealth = 6
```

```
Input:  accounts = [[1,5],[7,3],[3,5]]
Output: 10

Explanation:
1st customer = 6
2nd customer = 10
3rd customer = 8

Richest customer wealth = 10
```

---

## 💡 Approach
- Traverse each customer
- Calculate the total wealth of that customer
- Compare it with the maximum wealth found so far
- Return the maximum wealth

---

## ⚡ C++ Solution 

```cpp
class Solution {
public:
    int maximumWealth(vector<vector<int>>& accounts) {

        int maxWealth = 0;

        for(int i = 0; i < accounts.size(); i++){

            int wealth = 0;

            for(int j = 0; j < accounts[i].size(); j++){

                wealth += accounts[i][j];
            }

            maxWealth = max(maxWealth, wealth);
        }

        return maxWealth;
    }
};
```

## 🧪 Dry Run
