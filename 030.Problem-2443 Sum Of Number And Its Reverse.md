# 🔹 2443. Sum of Number and Its Reverse

## 🧠 Problem Statement
Given a non-negative integer `num`, return `true` if it can be expressed as:

:contentReference[oaicite:0]{index=0}

Otherwise, return `false`.

---

## 📌 Examples

```
Input:  num = 443
Output: true

Explanation:
172 + 271 = 443
```

```
Input:  num = 63
Output: false

Explanation:
No number and its reverse produce 63.
```

```
Input:  num = 181
Output: true

Explanation:
140 + 041 = 181
```

---

## 💡 Approach
- Try every number from `0` to `num`
- Reverse the current number
- Check:
  - `i + reverse == num`
- If found, return `true`
- Otherwise return `false`

---

## ⚡ C++ Solution 

```cpp
class Solution {
public:
    bool sumOfNumberAndReverse(int num) {

        for(int i = 0; i <= num; i++){

            int temp = i;

            int reverse = 0;

            while(temp > 0){

                int digit = temp % 10;

                reverse = reverse * 10 + digit;

                temp = temp / 10;
            }

            if(i + reverse == num){
                return true;
            }
        }

        return false;
    }
};
```
