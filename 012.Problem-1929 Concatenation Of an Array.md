# 🔹 1929. Concatenation of Array

## 🧠 Problem Statement
Given an integer array `nums` of length `n`, create an array `ans` of length `2n` where:

- `ans[i] == nums[i]`
- `ans[i + n] == nums[i]`

for `0 <= i < n`.

Return the concatenated array `ans`.

---

## 📌 Examples

```
Input:  nums = [1,2,1]
Output: [1,2,1,1,2,1]

Explanation:
ans = [nums[0], nums[1], nums[2],
       nums[0], nums[1], nums[2]]

ans = [1,2,1,1,2,1]
```

```
Input:  nums = [1,3,2,1]
Output: [1,3,2,1,1,3,2,1]
```

---

## 💡 Approach
- Create an empty vector `ans`
- Run a loop two times
- In each loop:
  - Traverse all elements of `nums`
  - Add each element into `ans`
- Return the final concatenated array

---

## ⚡ C++ Solution 

```cpp
class Solution {
public:
    vector<int> getConcatenation(vector<int>& nums) {

        vector<int> ans;

        for(int i = 0; i < 2; i++){

            for(int num : nums){
                ans.push_back(num);
            }
        }

        return ans;
    }
};
```

---

## 🧪 Dry Run

```cpp
nums = [1,2]

Initially:
ans = []

First Loop:
Add 1
Add 2

ans = [1,2]

Second Loop:
Add 1
Add 2

ans = [1,2,1,2]
```

---

## 🚀 Notes
- Time Complexity: O(n)  
- Space Complexity: O(n)
